## Oblig 2 Task (a): The stack and you

In the following example program we'll explore how to use the stack to pass arguments.
As before, we have a string that we would like to print.
The example program wraps printing into a little function `write` which we will `call`;
correspondingly it contains a `ret` statement at the end.

We prepare the arguments for the call on the stack before the call.

* **Fill in the beginning of the `write` function with *only* `pop` and `push` statements so that it can print the string and successfully return to the caller and exit!**
* Submit your file with the name `o2a.asm` as a text-file.

```
; o2a.asm
; 32-bit Linux x86, NASM syntax
;
;   Assemble :  nasm -f elf32 o2a.asm
;   Link     :  ld -m elf_i386 o2a.o -o o2a
;   Run      :  ./o2a
;   Output   :  Hello, DAT103!

section .data
    msg     db  "Hello, DAT103!", 10        ; 14 bytes (includes newline)
    len     equ $ - msg                     ; compile-time length constant

section .text
    global _start

_start:
    push    len                 ; 3rd argument  (count)
    push    msg                 ; 2nd argument  (buf)
    push    1                   ; 1st argument  (fd = stdout)
    call    write

    ; exit(0)
    xor     ebx, ebx            ; :-)
    mov     eax, 1
    int     0x80

;  write(fd, buf, count)
write:
    ??? ??? ???
    ??? ??? ???
    ??? ??? ???
    ??? ??? ???
    mov     eax, 4
    int     0x80
    ret

```

## Oblig 2 Task (b): Don't `push` me!

In the previous task, you had to make sure that the return address is pushed back onto the stack since it is of course at the top of the stack when we enter.
Now we will look for an alternative solution to Task (a), which...
* uses `mov` to load the arguments from the stack into the registers.
* addjusts the stack pointer to "*consume*" the arguments inside `write` since we didn't pop them explicitly.

So that you can check if you're doing it right (apart from not crashing), here is the sample with a safety net build in.
It indicates via the exit code 0 that you have cleaned up the stack correctly:

```
$ ./o2b
Hello, DAT103!
$ echo $?
0
```

* **Fill in the blanks in the following sample (it's the same logic as before, but now checks the stack pointer before and after). Do not use `pop` instructions. You might need a spare register such as `edi` or define more storage in the `.bss`-section.**
* Check that your program indeed exits with code 0.
* Submit your file with the name `o2b.asm` as a text-file.

```
section .data
    msg     db  "Hello, DAT103!", 10        ; 14 bytes (includes newline)
    len     equ $ - msg                     ; compile-time length constant

section .bss
    oldesp resd 1

section .text
    global _start

_start:
    mov     [oldesp], esp
    push    len                 ; 3rd argument  (count)
    push    msg                 ; 2nd argument  (buf)
    push    1                   ; 1st argument  (fd = stdout)
    call    write

    ; exit with safety net
    cmp     [oldesp], esp
    je      .equal
    mov     eax, 1              ; ooopsie
    jmp     .exit
.equal:
    xor     ebx, ebx            ; all good
.exit:
    mov     eax, 1
    int     0x80

;  write(fd, buf, count)
write:
    ??? ??? ???
    ??? ??? ???
    ??? ??? ???
    ??? ??? ???
    mov     eax, 4
    int     0x80
    ret

```

### Oblig 2 Task (c): Winter is coming...

It's (slowly) time to decorate the campus for Christmas! Let's print a Christmas tree:

```
$ ./xmas
          *
         ***
        *****
       *******
          *
          *
```

An easy way to draw this tree is the following:
* fix the *middle*-position of the tree, i.e. how many characters to the right the tip is;
* we'll print the tree and the stem separately;
* for the *i*th row of the tree (starting with row 0)...
    * ...we need (*middle*-*i*) spaces, and...
	* ... (2 * *i* + 1) stars `*`;
* for the stem you just print a few lines like row 0.

* **Write a `nasm` program named `xmas.nasm` that prints a reasonably sized tree using loops!**
    * Fix the *middle* position and the number of *rows* as constants in your program.
    * Use a loop over the number of rows to print a row.
    * Write a function `print_row` that prints a row. The function must expect the parameter *i* indicating the row on the stack.
    * Print the required number of spaces and stars using loops.
    * Call this function the required number of times, counting down the rows to zero. You may either use a loop or a recursive solution.
* Submit the file with the name `xmas.asm` in Canvas.

Other tips & remarks:
* You do not have to use a loop to call the `print_row`-function to print the stem.
* The easiest first approach is probably to repeatedly print single spaces or stars for a row. However, recall that syscalls are expensive. Once you got the simple version to work, try preparing one or two arrays of the required symbols on the stack, and print an entire row with only one or two syscalls!
